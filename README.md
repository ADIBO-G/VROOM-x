# VROOM-x
An adaptive high-speed line-following robot designed for maximum speed, stability, and accurate track navigation.

### Adaptive High-Speed & Stable Line-Following Robot

> Fast on Straights. Stable on Turns.

## 📌 About

VROOM is an ESP32-based autonomous line-following robot designed to achieve a balance between high speed, stability, and accurate track navigation.

Unlike conventional line-following robots that operate at a fixed speed, VROOM dynamically adjusts its speed according to the detected path conditions.

## 🎯 Objectives

- Achieve high-speed line following
- Maintain stable movement
- Reduce left-right oscillations
- Automatically adjust speed during turns
- Minimize overall track time

## 🔧 Hardware

- ESP32
- IR sensor array
- Motor driver
- 2 DC geared motors
- Wheels
- Caster wheel
- Chassis
- Battery

## 🚀 Key Features

- Adaptive speed control
- Stability optimization
- PWM motor control
- Automatic steering correction
- Low-cost design
